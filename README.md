# BotMine

A small Discord bot for reporting Minecraft server status.

Setup

1. Copy `.env.example` to `.env` and set `DISCORD_TOKEN` bằng token bot Discord của bạn.
2. Mở `server-ip.txt` và thay IP ở dòng không bắt đầu bằng `#`. Lệnh `//map` sẽ mở `http://<IP-server>:8100`; web map cần hoạt động trên cổng `8100`.
3. Install dependencies: `npm install`.
4. Start the bot: `npm start`.
